Building a Personal AI That Can Actually Act

Sihoo Squared v1 · September 2026

Most AI interfaces stop at conversation. I wanted to explore what changes when a personal assistant can move beyond answering and begin coordinating actions across a computer.

That project became Sihoo Squared, a personal AI system built around voice and chat, tool use, local context, memory, and explicit confirmation gates for actions that should never happen silently.

Conversation is only the front end

The useful work is underneath. Voice input needs transcription. Responses need speech output. Tasks need a queue so one slow action does not make the entire interface feel frozen. The assistant needs to understand what context is available and what should persist after the current interaction ends.

For the first release, I connected a speech pipeline using Groq Whisper, macOS text-to-speech, direct URL opening, queued work, and a memory/context layer. The point was not to imitate a science-fiction assistant. It was to learn what an assistant needs before it can become dependable.

Permission boundaries are product design

An assistant with tools needs more than capabilities. It needs rules about when not to act. Payments, destructive file operations, and other high-impact actions should require explicit confirmation. That friction is not a failure of automation; it is part of the interface.

I think of this as separating intent from authority. The model can infer that an action would help. It should not assume it has permission to execute every action it can describe.

Audit the system, not just the prompt

The project also pushed me to think about testing differently. A long prompt can look intelligent while the underlying system is unreliable. I added static audits and browser QA, but I also kept the remaining limitation visible: passing structured tests is not the same as proving every real macOS, local model, and speech path works under real use.

That distinction matters. Personal AI gets useful when the surrounding system is boringly reliable, not when the demo sounds impressive.
